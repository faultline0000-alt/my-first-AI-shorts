# AI가 바꾸는 미래 — Python 숏츠 만들기

**`shorts_사진` 폴더의 사진 3장**을 순서대로 사용해 **15초짜리 세로 영상**을 만듭니다.
처음 실행할 때 라이브러리를 내려받을 인터넷 연결이 필요합니다. 생성 자체에는 API 키가 필요하지 않습니다.

## 1. 준비하기

Python **3.10 이상**을 설치하세요. Windows에서는 설치 화면에서 `Add Python to PATH`를 체크하세요.
이 프로젝트 폴더를 열고 터미널을 실행하세요. 아래 명령어는 한 줄씩 입력하고 Enter를 누르면 됩니다.

## 가장 쉬운 방법: 웹 화면에서 만들기


**Windows에서는 최초 설치를 마친 뒤 `실행.bat`을 더블클릭하세요.**
`app.py`, `launch.py`, `실행.bat`, `.venv` 폴더가 같은 프로젝트 폴더에 있어야 합니다.
서버가 준비되면 브라우저가 자동으로 열립니다. 주소를 매번 입력할 필요가 없습니다.
이미 프로그램이 실행 중이면 기존 화면을 엽니다. 실행 창은 사용하는 동안 열어 두세요.
종료하려면 실행 창에서 Ctrl+C를 누르세요.
`실행.bat`은 Windows 실행용 파일입니다. Python은 먼저 설치해야 하며,
가상환경이나 필수 라이브러리가 없으면 처음 실행할 때 자동으로 설치합니다(인터넷 필요).

아래의 라이브러리 설치를 먼저 완료한 뒤, 프로젝트 폴더의 터미널에서 실행하세요.

Windows:

```powershell
.venv\Scripts\python app.py
```

macOS / Linux:

```bash
.venv/bin/python app.py
```

1. 브라우저 주소창에 `http://127.0.0.1:8000`을 입력하세요. 프로그램을 실행한 **같은 컴퓨터**에서 여는 주소입니다.
2. 장면 1, 2, 3에 사용할 사진을 한 장씩 고르세요. 사진 파일명을 바꾸거나 폴더에 넣을 필요가 없습니다.
3. 사진마다 원하는 자막을 입력하세요(각 1~60자). 긴 문장은 줄바꿈되며, 너무 길면 줄여 달라는 안내가 나옵니다.
4. 노란색으로 강조할 단어를 쉼표로 구분해 입력하세요. 강조가 필요 없으면 비워 두세요.
5. **내레이션 목소리**에서 차분한 한국어 남성(기본), 또렷한 여성 또는 음성 없음을 고르세요.
6. **15초 영상 만들기**를 누르고 완료될 때까지 기다리세요. 보통 몇 분 정도 걸립니다.
7. 완성 영상을 화면에서 재생하고 **MP4 다운로드**를 누르세요.

사진은 장면마다 5초씩 사용하며 1080×1920 / 30fps의 MP4를 만듭니다.
전체 업로드는 약 31MB 이하, 사진 한 장은 2,500만 화소 이하로 준비하세요.
웹에서 만든 영상은 브라우저로 전달되며, PC의 다운로드 폴더에 저장할 수 있습니다.
기존 `output/ai_shorts.mp4`는 덮어쓰지 않습니다. 작업용 사진과 임시 영상은 전송 준비 후 삭제됩니다.
화면을 새로 고치기 전에 다운로드하세요. 서버는 한 번에 한 영상씩 제작합니다.

종료하려면 터미널에서 **Ctrl+C**를 누르세요. 다음에 사용할 때 다시 `app.py`를 실행하면 됩니다.
이 앱은 개인 컴퓨터용 로컬 웹 앱입니다. GitHub에 코드를 올리는 것만으로 웹사이트가 공개되지는 않습니다.
클라우드 작업 환경에서 실행한 주소는 사용자 PC에서 직접 열 수 없습니다.

## 터미널로 만드는 방법

웹 화면 없이 아래 방식으로도 제작할 수 있습니다.

## 한국어 내레이션

- 기본은 차분한 한국어 남성 합성 음성(`ko-KR-InJoonNeural`)이며 실제 인물의 목소리를 복제하지 않습니다.
- 여성 음성(`ko-KR-SunHiNeural`)과 음성 없음도 선택할 수 있습니다.
- 자막을 장면 시작 0.3초 뒤부터 읽습니다. 5초 안에 맞추되 끝을 잘라내지 않습니다.
- 조금 긴 문장은 최대 1.35배까지 속도를 맞춥니다. 더 길면 자막을 줄여 달라고 안내합니다.
- `AI`는 한국어로 자연스럽게 읽도록 `에이아이`로 바꿔 합성합니다.
- 자막 텍스트는 Microsoft 온라인 음성 서비스로 전달됩니다. 사진은 전달하지 않습니다.
- 인터넷 연결이 필요합니다. 이 프로젝트에서는 API 키 입력 없이 `edge-tts`를 사용하며,
  외부 서비스의 가용성에 따라 실패할 수 있습니다. 서비스 이용 조건도 확인하세요.
- 연결 실패 시 명확한 오류를 표시합니다. 몰래 무음 영상으로 대체하지 않습니다.
- CLI 기본값도 남성입니다. 무음 제작은 `python make_video.py --voice none`을 사용하세요.

**기존 사용자:** GitHub 최신 파일을 기존 프로젝트 폴더에 덮어쓰되 `.venv`는 보존하세요.
`실행.bat`을 다시 실행하면 새 라이브러리가 없을 때 설치하고 웹 화면을 엽니다.
기존 실행 창은 먼저 Ctrl+C로 종료하세요.

## 사진 넣기

프로젝트 폴더에 `shorts_사진` 폴더를 만들고 사진 3장을 넣으세요.
원하는 순서대로 `01.jpg`, `02.jpg`, `03.jpg`처럼 이름을 붙이면 됩니다.
사진은 파일명에 있는 숫자를 고려해 정렬합니다(1, 2, 10 순서).
JPG, JPEG, PNG, WebP, BMP, TIFF를 지원하며 사진은 정확히 3장이어야 합니다.
사진이 없으면 안내 메시지와 함께 종료하고 기존 출력 영상은 건드리지 않습니다.
휴대폰 사진의 회전을 자동 보정합니다. 사진 전체를 흐린 배경 위에 올려
가로 사진 속 인물이 잘리지 않도록 합니다. 줌인에 필요한 여백도 확보합니다.
직접 촬영했거나 사용 권한이 있는 사진을 사용하세요.

다른 폴더를 쓰려면 실행 명령 뒤에 `--photos "사진 폴더 경로"`를 붙이세요.
예: `.venv/bin/python make_video.py --photos "/경로/shorts_사진"`

macOS 또는 Linux:


가상환경(`.venv`)은 이 프로젝트에서 쓸 라이브러리를 따로 보관하는 폴더입니다.
별도로 활성화하지 않아도 위 명령어대로 실행하면 됩니다.

Windows:

macOS 또는 Linux:

완성된 파일은 프로젝트의 **`output/ai_shorts.mp4`**입니다. 파일을 더블클릭해서 재생하세요.
다시 실행하면 기존 결과 파일을 덮어씁니다. 중요한 결과는 먼저 다른 이름으로 보관하세요.

## 영상 구성

| 시간 | 코드로 그린 배경 | 사진 아래의 강조 자막 |
| --- | --- | --- |
| 0~5초 | 첫 번째 사진 | AI 시대, 내 일은 안전할까? |
| 5~10초 | 두 번째 사진 | 반복 업무부터 바뀌고 있습니다 |
| 10~15초 | 세 번째 사진 | AI에게 맡기고 싶은 일은? |

- MP4 / H.264, 1080×1920, 세로 9:16, 30fps, 총 15초입니다. 한국어 내레이션을 선택할 수 있습니다.
- 사진마다 5초 동안 천천히 약 6% 확대합니다. 전환 부근에는 0.2초 페이드 효과가 적용됩니다.

- 자막은 최대 112px의 큰 글씨로 표시하며, 긴 문장은 자동 줄바꿈·크기 조절합니다. 검정 반투명 띠·외곽선·그림자를 사용합니다.
- AI, 안전, 반복 업무, 맡기고 등 핵심 단어는 노란색으로 강조합니다.
- 각 장면 시작 때 자막이 화면 아래에서 사진 아래쪽으로 0.6초 동안 올라오며 부드럽게 감속합니다.
- 사용자가 준비한 사진과 선택한 AI 합성 음성을 사용합니다. 배경 음악은 넣지 않습니다.

## 한글이 나오지 않거나 폰트 오류가 날 때

프로그램은 Windows의 맑은 고딕, macOS의 Apple SD Gothic Neo,
Linux의 Noto CJK 또는 나눔고딕 폰트 파일이 있는지 확인합니다.
폰트가 없으면 설명을 출력하고 종료합니다. 임의 폰트를 지정할 때는 한글을 지원하는 폰트인지 확인하세요.

Ubuntu/Debian에서는 다음 명령으로 설치할 수 있습니다(관리자 권한 필요).

```bash
sudo apt-get update
sudo apt-get install -y fonts-noto-cjk
```

다른 운영체제에서는 Google Fonts의 **Noto Sans KR**을 내려받아 압축을 풀고,
실제 `.ttf` 파일을 프로젝트의 `fonts` 폴더에 `NotoSansKR-Regular.ttf`라는 이름으로 넣으세요.
Noto 폰트는 SIL Open Font License로 배포됩니다. 폰트를 재배포할 때 라이선스 파일도 함께 보관하세요.
또는 설치된 한글 폰트의 경로를 직접 지정할 수 있습니다.

```bash
.venv/bin/python make_video.py --font "/폰트가/있는/경로/NotoSansKR-Regular.ttf"
```

Windows에서는 위 명령의 `.venv/bin/python` 대신 `.venv\Scripts\python`을 사용하세요.
`KOREAN_FONT` 환경 변수로 경로를 지정하는 방법도 지원합니다.

## 자주 만나는 문제

- `No module named moviepy`: 2단계에서 사용한 가상환경 Python으로 3단계를 실행했는지 확인하세요.
- FFmpeg 오류: 인터넷이 연결된 상태에서 라이브러리 설치를 다시 확인하세요. 기본적으로 imageio-ffmpeg가 제공하는 실행 파일을 사용합니다. 별도 FFmpeg를 쓴다면 실행 전에 `IMAGEIO_FFMPEG_EXE`에 실행 파일 경로를 설정하세요.
- 출력 파일이 안 보임: 터미널에 표시되는 `완료:` 뒤의 절대 경로를 확인하세요.

## 코드 살펴보기

`make_video.py`의 `CAPTIONS`를 바꾸면 자막을 수정할 수 있습니다.
노란색 강조 단어는 `HIGHLIGHT_WORDS`, 등장 속도는 `CAPTION_ENTRY_SECONDS`에서 바꿀 수 있습니다.
`load_photo()`는 Pillow로 사진 크기·회전·흐린 배경을 처리하고, `main()`은 MoviePy 2.x로 확대·전환·저장을 담당합니다.
`requirements.txt`에는 설치할 라이브러리 버전이 들어 있습니다.
`app.py`는 웹 서버, `templates/index.html`과 `static/`은 웹 화면입니다.
웹과 터미널 모두 `render_video()`를 사용합니다.

인물을 가리지 않도록 자막은 사진 아래쪽에 표시합니다.

## 검증 상태

업로드된 사진 3장으로 실제 영상을 생성했습니다. FFprobe로 15.000초,
1080×1920, 30fps, 450프레임, H.264를 확인했고 전체 디코딩도 오류 없이 통과했습니다.
각 장면의 실제 출력 프레임에서 사진 순서와 인물이 잘리지 않는 배치를 확인했습니다.


## 웹 기능 검증

- 자동 검사: `python -m unittest discover -s tests -v` (11개)
- 브라우저에서 사진 미리보기·입력·결과 표시·다운로드 및 모바일 배치 확인
- 실제 로컬 HTTP 업로드 요청으로 사용자 자막을 넣은 MP4 다운로드 응답 확인
- 생성된 영상의 15초 / 1080×1920 / 30fps / 450프레임 및 전체 디코딩 확인

웹 브라우저 동작 검사는 검증용 MP4 응답으로, 실제 영상 제작은 별도 HTTP 요청으로 확인했습니다.


## 음성 기능 검증의 범위

장면별 오디오 배치·길이 조절·과도하게 긴 자막 거부는 시험용 오디오로 검사했습니다.
이 클라우드 환경에서는 `speech.platform.bing.com` 연결이 정책상 HTTP 403으로 차단되어
실제 한국어 합성 음성의 생성·음질은 아직 검증하지 못했습니다.
기존 다운로드용 `output/ai_shorts.mp4`는 무음 버전이며 음성 완성본으로 교체하지 않았습니다.
클라우드에서 직접 합성하려면 환경 설정의 허용 도메인 초안을 검토·저장하고 게시한 뒤 재검증해야 합니다.
일반 PC에서는 인터넷 연결 후 웹 화면에서 제작할 수 있습니다.
